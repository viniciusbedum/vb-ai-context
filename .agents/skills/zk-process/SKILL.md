# My Thinking process

Preserve the distinction between captured material, literature notes, and durable claims.

## Workflow

1. Read the selected note and nearby My Thinking indexes. Follow relevant links rather than scanning unrelated areas.
2. Determine whether the material is a fleeting capture, a source interpretation, or a durable single idea.
3. Clarify it in the user's own words. Split only when multiple independently useful claims are present.
4. Create or update the minimum appropriate note type using the templates in `Z05 ⛓️ Systems/Templates/`:
   - floating note for an undeveloped idea
   - literature note for ideas tied to a specific source
   - permanent note for one self-contained, reusable claim
5. Add meaningful links to existing My Thinking notes and a direct link from every applicable index.
6. Do not delete or move the input note unless the user explicitly asks. Never edit KB raw material as part of this workflow.
7. Verify that each new link resolves, the note states one clear purpose, and the result does not merely duplicate an existing note.

When context is incomplete, leave explicit questions instead of inventing the user's position. If the material first needs external-source curation, use `$kb-ingest`; if a curated concept needs to enter personal thinking, use `$kb-promote`.
