# Raw articles

This folder preserves articles, newsletters, blog posts, and other article-like web sources.

Put the captured source content here. Do not put source summaries, personal notes, or edited versions of an existing raw file here.

The `kb-ingest` skill uses this folder when the source type is an article.

For browser capture, [[integrations]] explains how to send a complete article here with the optional Obsidian Web Clipper template. Inspect the preview before saving. After the file lands here, preserve it unchanged and put every summary or interpretation in `X03 🗃️ Knowledge Base/02 🧠 Wiki/sources/`.
