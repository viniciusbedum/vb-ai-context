# Raw assets

This folder preserves source media that belongs to an external Knowledge Base source.

Put permitted images or other supporting media here. Do not use it for personal attachments, which belong in `X04 📎 Attachments/`, or for curated Markdown notes.

No current skill writes here automatically. Add an asset deliberately when it belongs to a source you are allowed to keep.
