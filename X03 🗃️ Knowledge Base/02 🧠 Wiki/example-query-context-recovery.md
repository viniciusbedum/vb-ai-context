# Example query: context recovery after an interruption

## Answer

This Knowledge Base supports a narrow working hypothesis: leaving a compact note before a pause may reduce the effort needed to resume a task. The proposed note contains the current state, next action, and open question. See [[context-packets]] and [[restart-cost]].

The available evidence is a single fictional exploratory source, [[cedar-lane-workshop-source]]. It reports participant experience but provides no controlled measurement or long-term result. A stronger claim would require additional sources.

## Practical test

Use a three-line context packet for one recurring task. Track whether the next session begins with less reconstruction. Treat the result as local evidence, not a universal conclusion.
