# Decision

## Decision

Renamed the project from "VB AI Base" to "VB AI Context".

## Context

"Base" is generic and doesn't signal the product's core mechanic. "Context" matches the theme already central to the fictional demo content (context packets, restart cost) and the current "context engineering" conversation in AI tooling, sidestepping the crowded "second brain / Obsidian" naming space.

## Alternatives considered

Keeping "VB AI Base" — rejected once "Context" was identified as a more accurate, more differentiated name. Renaming after publishing would have been far more expensive than renaming pre-launch.

## Consequences

Every file referencing the old name needed updating before the first public release.
