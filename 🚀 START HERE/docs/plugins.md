# Obsidian plugins

Obsidian is optional. The base vault is configured to work without community plugins.

## Native features

The included `.obsidian` files configure a small set of native behavior for Markdown editing, templates, daily notes, graph navigation, and backlinks. Native features may be enabled or disabled in Obsidian Settings without changing the underlying notes.

## Community plugins

No community plugin is required. Add one only when a recurring need is clear.

Before installing a plugin:

1. read its current permissions and documentation;
2. check whether it is actively maintained;
3. back up the vault;
4. test it with fictional data;
5. document why it is required if other users must install it.

Avoid making a core workflow depend on a plugin-specific syntax. Portable Markdown and ordinary wikilinks should remain readable when the plugin is absent.

## Browser clipping

Web clipping is an optional integration, not a required Obsidian plugin. See [[integrations]] for the fallback workflow.
